# Devoted, a Yuzuru Fushimi shrine

**Devoted** is a fan site/page devoted to **Yuzuru Fushimi** from the Japanese mobile rhythm game **Ensemble Stars**. It is hosted on Nekoweb under the URL [devoted.nekoweb.org](https://devoted.nekoweb.org) and generated using Lume static site generator.
